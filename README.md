# AxoLink

AxoLink is an open-source Flutter companion application for a smart insulin
storage box.

The project is designed to provide a simple digital interface for interacting
with the smart box and managing device-related information.

## Purpose

AxoLink explores how mobile software can work with connected hardware to
improve the usability and management of insulin storage devices.

This project is intended as a software and IoT project and does not provide
medical advice or replace professional medical care.

## Features

- Flutter mobile application
- Firebase integration
- Smart insulin box connectivity
- Device information and status monitoring
- User-friendly mobile interface
- Android and iOS support

## Tech Stack

- Flutter
- Dart
- Firebase
- GitHub Actions

## Project Structure

- `lib/` – Flutter application source code
- `assets/` – Application assets
- `android/` – Android configuration
- `ios/` – iOS configuration
- `test/` – Application tests

## Getting Started

### Requirements

- Flutter SDK
- Dart
- Android Studio or VS Code
- Firebase project

### Installation

Clone the repository:

git clone https://github.com/charukayapa/AxoLink.git

Enter the project directory:

cd AxoLink

Install dependencies:

flutter pub get

Run the application:

flutter run
